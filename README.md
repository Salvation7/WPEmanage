# 壁纸库 · Wallpaper Shelf

Windows 桌面工具，用于浏览本机 Wallpaper Engine 项目、批量整理视频文件，并记录每次移出的视频与对应的创意工坊项目。

## 主要功能

- **扫描和预览壁纸**。自动发现 Steam 创意工坊、本地项目和内置壁纸，也可添加其他目录。方格显示 `MP4`、`PKG`、`HTML` 等实际文件格式，支持搜索、筛选、排序、播放视频预览和定位原文件。
- **批量选择**。左键拖出矩形框选，拖到列表边缘可自动滚动。`Ctrl` 加单击逐项增减，`Shift` 加单击连续选择。`Ctrl+A` 全选当前结果，`Esc` 清空或撤回本次框选。
- **复制、移动和查看进度**。将选中的视频转存到同一个目标目录，支持跨盘移动。同名文件自动加序号。点击左栏「传输」可查看总体进度、当前文件和已处理大小，完成后显示逐项结果。
- **保存移动记录**。每批完成后自动保存成功移动的文件、时间和目标目录。重启后可从左栏「移动记录」查看原批次、打开目标目录、复制工坊项目名称与 ID，或直达对应页面。
- **整理工坊退订清单**。移动结果会列出符合条件的工坊项目。可在 Wallpaper Engine 的「已安装」中按住 `Ctrl` 多选已核对的项目，右键选择「取消订阅」。「视频缺失」提供另一个入口，用于核对以前移出的项目并复制清单。

## 打开便携版

完整解压 Windows x64 便携版 ZIP，双击文件夹内的 `WallpaperShelf.exe`。升级时先退出旧版。移动记录保存在当前 Windows 用户的应用数据中。

## 从源码运行和打包

在 Windows 的项目目录中安装运行时并启动应用。

```powershell
npm.cmd ci
npm.cmd exec -- install-electron
npm.cmd start
```

打包命令会在 `dist` 下生成带版本号的 Windows 便携文件夹和 ZIP。

```powershell
npm.cmd run build -- --versioned
```
